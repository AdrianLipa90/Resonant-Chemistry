\chapter*{Current textbook status}
\addcontentsline{toc}{chapter}{Current textbook status}
This document is a working research textbook.  Conventional atomic-control results retain their declared validation status; the shell-topology, conformal knot--shell and relational/TIR layers remain candidates unless explicitly stated otherwise.  The current correlation frontier is the first state-averaged active--external orbital-relaxation gate for carbon, followed by multidimensional MCSCF if that gate is variationally informative.  The current topology frontier is a shell-only particle--hole and principal-shell transfer test before any joint knot comparison.
