\section{No hidden physical authority}
A function name, semantic-card field or 36D encoding is not granted physical authority by appearing in this map.  The equation in the textbook and the benchmark acceptance rule jointly define what the implementation is supposed to compute.  If code and documentation diverge, the discrepancy is a defect to be resolved rather than permission to reinterpret the equation silently.

\section{Reproducibility convention}
Every new solver module should ship with: a deterministic or tolerance-bounded test; a machine-readable benchmark when numerical output is scientifically discussed; a monograph section giving the governing equations and approximations; and a receipt or commit reference sufficient to identify the tested implementation.  Exploratory notebooks or dashboards may visualize results, but they are not the sole repository of a scientific claim.
