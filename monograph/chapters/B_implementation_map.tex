\section{Control backend boundary}
The v0.14 molecular relaxation module uses PySCF/geomeTRIC as conventional numerical backends.  Those packages do not define the Resonant-Chemistry relational state taxonomy, gate semantics or scientific promotion rules.  The project layer defines the frozen method policy, common seed generation, failure preservation and receipts; the backend supplies conventional electronic energies, gradients and geometry optimization.

Future orchestration may expose the same operations through a PhaseNav-native command/gate surface.  Such orchestration must preserve the conventional results and provenance and may not rewrite a backend failure or energy to satisfy a relational hypothesis.

\section{No hidden physical authority}
A function name, semantic-card field or 36D encoding is not granted physical authority by appearing in this map.  The equation in the textbook and the benchmark acceptance rule jointly define what the implementation is supposed to compute.  If code and documentation diverge, the discrepancy is a defect to be resolved rather than permission to reinterpret the equation silently.

\section{Reproducibility convention}
Every new solver or candidate module should ship with: a deterministic or tolerance-bounded test; a machine-readable benchmark/receipt when numerical output is scientifically discussed; a monograph section giving the governing equations and approximations; and provenance sufficient to identify the tested implementation.  Exploratory notebooks or dashboards may visualize results, but they are not the sole repository of a scientific claim.

Merged changes that alter implementation status, validation state or the current open gate must trigger documentation reconciliation.  `main` is the project Source of Truth; historical research branch names are not a substitute for current repository state.
