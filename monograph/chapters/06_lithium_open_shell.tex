\chapter{Lithium: The First Open-Shell Atom}

\section{Why lithium changes the problem}
Lithium is the first atom in the present construction whose neutral ground configuration is open-shell,
\begin{equation}
1s^2\,2s^1,
\end{equation}
with three electrons and a doublet-$S$ control target. A closed-shell restricted Hartree--Fock ansatz is therefore no longer appropriate. The control layer must distinguish the two spin sectors while preserving the Pauli principle and same-spin exchange.

\section{Radial unrestricted Hartree--Fock control}
Version 0.1 uses a spherical radial unrestricted Hartree--Fock (UHF) model restricted to $s$ orbitals. The spin occupancies are
\begin{equation}
N_\alpha=2,\qquad N_\beta=1.
\end{equation}
For each spin sector,
\begin{equation}
F_\sigma=h+\sum_j J_j-\sum_{j\in\sigma}K_j,
\end{equation}
where $h$ contains radial kinetic energy and nuclear attraction, $J_j$ is the Coulomb contribution of occupied orbital $j$, and $K_j$ is included only for same-spin orbitals.

For spherical $s$ orbitals the Coulomb kernel after angular integration is
\begin{equation}
G(r,r')=\frac{1}{\max(r,r')}.
\end{equation}
The exchange operator remains nonlocal and is therefore represented as a dense radial matrix rather than replaced by a local screening potential.

\section{Energy functional}
For occupied spin orbitals $\{\phi_i\}$,
\begin{equation}
E_{\mathrm{UHF}}=\sum_i\langle i|h|i\rangle+
\frac12\sum_{ij}\left[J_{ij}-\delta_{\sigma_i\sigma_j}K_{ij}\right].
\end{equation}
Self-Coulomb terms cancel exactly against self-exchange for a given spin orbital.

\section{Spin diagnostic}
An unrestricted determinant need not be an exact eigenstate of $\hat S^2$. For $N_\alpha=2$ and $N_\beta=1$, the diagnostic used here is
\begin{equation}
\langle S^2\rangle=S_z(S_z+1)+N_\beta-
\sum_{ij}|\langle\phi_i^\alpha|\phi_j^\beta\rangle|^2.
\end{equation}
The ideal doublet value is $S(S+1)=3/4$. On the 801-point control grid, the present solver gives approximately
\begin{equation}
\langle S^2\rangle\approx0.7500161,
\end{equation}
so spin contamination is approximately $1.61\times10^{-5}$.

\section{Grid convergence}
The raw radial discretization converges from above. With $r_{\max}=30\,a_0$ the current implementation gives approximately
\begin{align}
E_{400}&=-7.333144359\,E_h,\\
E_{801}&=-7.407328552\,E_h.
\end{align}
Using the same second-order Richardson convention as the helium control,
\begin{equation}
E_{\mathrm{R}}=\frac{4E_{801}-E_{400}}{3}
\approx -7.432056616\,E_h.
\end{equation}
The external Hartree--Fock reference used only for diagnosis is approximately $-7.432727\,E_h$, so the present spherical radial control is within roughly $9.0\times10^{-5}$ relative error. This reference value is not an input to the SCF iteration.

\section{Virial diagnostic}
On the 801-point grid the energy components are approximately
\begin{align}
T&=7.356885300\,E_h,\\
V_{\mathrm{nuc}}&=-17.041160101\,E_h,\\
V_{ee}&=2.276946249\,E_h,
\end{align}
with a finite-grid virial residual
\begin{equation}
2T+V_{\mathrm{nuc}}+V_{ee}\approx-0.0504433\,E_h.
\end{equation}
Unlike the extrapolated total energy, this raw-grid residual is not yet extrapolated and remains a convergence diagnostic.

\section{Semantic-card consequences}
Lithium introduces new card features that were absent for helium: an open valence shell, a nonzero spin degree of freedom, a distinction between $\alpha$ and $\beta$ state sectors, and a measurable spin-purity diagnostic. These quantities are physical control descriptors. No TIR or affective meaning is assigned to them in version 0.1.
